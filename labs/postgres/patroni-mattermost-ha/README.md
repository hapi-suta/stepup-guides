# Patroni HA with Mattermost

An enrolled-learner, eight-role production-simulation Journey. The machine-readable
source of step order, role targeting and validation is `journey.json`. Markdown
guides explain the same actions; they never independently award progress.

The clean baseline is verified. Disruptive SURVIVE scenarios remain visibly locked
until a separate approved failure/replay canary passes.

## Instructor-led class

[Start the classroom guide](classroom/README.md): prepared servers, separate commands, full configuration files, checkpoints and an instructor-owned application handoff. Includes a downloadable plain-text manual and an explicit testing-status note.
