# Module 01 - An LLM Call From Scratch

Part of the Agentic AI Engineering track. Send your first requests to Claude from plain Python, read what comes back, and learn the three facts every agent is built on: a call is stateless, memory is the message list you resend, and every token costs money.

**Environment:** one CentOS Stream 9 server (**ai-lab**), user **ec2-user**. Python 3.12 and the pinned libraries are installed in Build 01. Calls go through the SUTA LLM proxy with your personal $5-capped key (`~/.suta-llm.env`, put there by Prof. Happy's tooling).

**Time:** 2-3 hours
