# Module 03 - Python You Can Defend I

Part of the AI Engineer track. In Module 02 you pasted the tools your agent calls. In this module you write tools yourself: take a PostgreSQL log line apart by hand, group records with lists and dictionaries, make a function fail with a clear error, and prove all of it with tests. The module ends with a function you write alone from a specification.

**Environment:** the same **ai-lab** server and `~/agentic-ai` workspace as Module 02, user **ec2-user**. You work on the sample log `data/postgresql.log` from Module 02. No LLM calls are made in this module, so it costs nothing on your key.

**Time:** 4-6 hours

**You need before you start:** Module 02 Build 01 finished (`data/postgresql.log` has 15 lines and `tools.py` exists).
