## How to Use

1. Your instructor will provide you with server IPs and SSH keys
2. Follow the BUILD guides in order for your assigned module

   - [01 - Server Preparation](postgres/module09-backup-pitr/build/01-server-prep.md)

   - [03 - Logical Backups](postgres/module09-backup-pitr/build/03-logical-backups.md)
   - [04 - Logical Restore](postgres/module09-backup-pitr/build/04-logical-restore.md)
   - [05 - Physical Backup](postgres/module09-backup-pitr/build/05-physical-backup.md)
   - [06 - Point-in-Time Recovery](postgres/module09-backup-pitr/build/06-pitr.md)

   - [08 - pgBackRest Operations](postgres/module09-backup-pitr/build/08-pgbackrest-operations.md)

### Module 02 - Architecture (Guides 01-04)
   - [01 - Process Architecture](postgres/module02-architecture/build/01-process-architecture.md)
   - [02 - Memory Architecture](postgres/module02-architecture/build/02-memory-architecture.md)

3. Each guide builds on the previous one - do not skip ahead
4. Message your instructor when you complete the BUILD phase

## Lab Structure

Each lab has up to four sections:

- **build/** - Step-by-step setup guides (start here)
- **use/** - Practice exercises
- **survive/** - Troubleshooting runbooks
- **concepts/** - Reference material
