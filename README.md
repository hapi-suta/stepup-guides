# SUTA Labs - PostgreSQL Hands-On Guides

Step-by-step lab guides for learning PostgreSQL administration.

## Available Labs

| Lab | Topic | Guides |
|-----|-------|--------|
| [backup-pitr](postgres/backup-pitr/) | Backup, Recovery, and Point-in-Time Recovery | 8 BUILD guides |

## How to Use

1. Your instructor will provide you with server IPs and SSH keys
2. Follow the BUILD guides in order (01 through 08)
3. Each guide builds on the previous one - do not skip ahead
4. Message your instructor when you complete the BUILD phase

## Lab Structure

Each lab has up to four sections:

- **build/** - Step-by-step setup guides (start here)
- **use/** - Practice exercises
- **survive/** - Troubleshooting runbooks
- **concepts/** - Reference material

## Questions?

Contact your instructor for help with any step.
