# SUTA Labs - PostgreSQL Hands-On Guides

Step-by-step lab guides for learning PostgreSQL administration.

## Available Labs

| Lab | Topic | Guides |
|-----|-------|--------|
| [backup-pitr](postgres/backup-pitr/) | Backup, Recovery, and Point-in-Time Recovery | 8 BUILD guides |

## How to Use

1. Your instructor will provide you with server IPs and SSH keys
2. Follow the BUILD guides in order (01 through 08):
   - [01 - Server Preparation](postgres/backup-pitr/build/01-server-prep.md)
   - [02 - Install PostgreSQL](postgres/backup-pitr/build/02-install-postgresql.md)
   - [03 - Logical Backups](postgres/backup-pitr/build/03-logical-backups.md)
   - [04 - Logical Restore](postgres/backup-pitr/build/04-logical-restore.md)
   - [05 - Physical Backup](postgres/backup-pitr/build/05-physical-backup.md)
   - [06 - Point-in-Time Recovery](postgres/backup-pitr/build/06-pitr.md)
   - [07 - Install pgBackRest](postgres/backup-pitr/build/07-install-pgbackrest.md)
   - [08 - pgBackRest Operations](postgres/backup-pitr/build/08-pgbackrest-operations.md)
3. Each guide builds on the previous one - do not skip ahead
4. Message your instructor when you complete the BUILD phase

## Lab Structure

Each lab has up to four sections:

- **build/** - Step-by-step setup guides (start here)
- **use/** - Practice exercises
- **survive/** - Troubleshooting runbooks
- **concepts/** - Reference material

## Questions?

Contact your instructor for help with any step.
