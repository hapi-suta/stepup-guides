# Module 2: PostgreSQL Architecture Deep Dive

Explore the internals of PostgreSQL - processes, memory, storage, and query
processing - so you can tune, troubleshoot, and explain what the engine is
actually doing under the hood.

## Available Labs

| # | Guide | Topic | Time |
| - | ----- | ----- | ---- |
| 1 | `build/01-process-architecture.md` | Process Architecture Explorer | 45 min |
| 2 | `build/02-memory-architecture.md` | Memory Architecture | 45 min |
| 3 | `build/03-storage-architecture.md` | Storage Architecture | 60 min |
| 4 | `build/04-query-processing.md` | Query Processing Pipeline | 45 min |

All labs run on **NODE1 only**.

## How to Use

1. Work through the guides in order (01 through 04).
2. Each guide is self-contained - read the explanation, run the commands, and
   answer the checkpoint questions before moving on.
3. Do not skip ahead. Later guides build on concepts from earlier ones.

## Prerequisites

- `postgres/backup-pitr` lab completed
- PostgreSQL 16 running on NODE1
