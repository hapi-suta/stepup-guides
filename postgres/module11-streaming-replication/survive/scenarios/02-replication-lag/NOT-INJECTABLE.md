Not injectable: the runbook diagnoses a heavy write load, slow standby I/O or a network bottleneck, none of which can be produced reliably from one script (async replication on a LAN stays near zero lag, and a paused replay via pg_wal_replay_pause would not match the runbook's diagnosis or be undone by its fix path, which cancels a load rather than resuming replay). Tutor: have the learner run pgbench against the primary themselves, then walk the runbook from the pasted pg_stat_replication output.
